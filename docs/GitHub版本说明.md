# 本地展示候选版本

第一版目标是产品与技术展示并支持本地复现，核心面向香水新手，以耳机验证多品类。没有上传、提交或创建远程仓库。

已实现三入口共用流程、多品类真实事实目录、预算/属性过滤、解释来源、选择记录、笔记图文总结及自动提取、本地图文、mock/real启动、可选真实笔记导入。

公开候选包的边界：允许列表收集src、当前手机前端、有来源的笔记整理、已核验数据、安装与测试文件；不携带旧原型参考图片、真实笔记正文与会话、MCP服务/cookies、个人配置或既有评测结果。当前原17条商品只导出身份字段，已核验事实由overlay载入，未核资料不推荐。本地原数据保留，包内首页使用有来源的笔记整理和原生示意封面；原英文资料卡仅留内部测试。

发布前建议完成：人工体验一遍三入口；小批真实模型端到端与节点质量评测（单列失败、成本和耗时）；确认名称、素材和代码许可证；检查候选包无账号数据；最后再创建GitHub仓库。该项目尚未提供线上多人部署、登录权限、实时库存、交易或全网商品搜索。

许可证由项目所有者选择。第三方产品名称、商标与官方资料不随代码获得重新授权。来源链接和核验日期用于追溯，不能替代许可审核。
